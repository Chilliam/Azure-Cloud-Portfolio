# Weekly Study Schedule: IT Support → Azure Admin

Assumes **8–10 hours/week** of study time (evenings + one weekend block). Adjust pace up or down — the sequencing matters more than the exact week count. Total: ~26 weeks (~6 months) to be interview-ready with AZ-104 + a working portfolio.

---

## Weeks 1–4: AZ-900 + Portal Familiarity

| Week | Focus | Deliverable |
|---|---|---|
| 1 | Cloud concepts, shared responsibility model, Azure account setup | Azure free account activated, portal explored |
| 2 | Core services: compute, storage, networking overview | Deploy your first VM manually |
| 3 | Identity basics (Entra ID), pricing/SLA/lifecycle concepts | Complete Microsoft Learn AZ-900 path |
| 4 | Practice exams + review weak areas | **Sit AZ-900 exam** |

---

## Weeks 5–10: AZ-104 Core Content

| Week | Focus | Deliverable |
|---|---|---|
| 5 | Identity & governance (Entra ID, RBAC, Policy, management groups) | Set up test tenant with users/groups + custom RBAC role |
| 6 | Storage (accounts, redundancy, tiers, file shares, lifecycle mgmt) | Deploy storage account with lifecycle policy |
| 7 | Compute (VMs, availability sets/zones, scale sets, sizing) | **Start Project 1**: deploy web+DB VM pair |
| 8 | Networking (VNets, subnets, NSGs, peering, load balancers) | Finish Project 1 network + load balancer |
| 9 | Monitoring (Azure Monitor, Log Analytics, alerts) + backup/recovery | **Start Project 4**: monitoring dashboard + alerts |
| 10 | Review week — consolidate notes, redo labs you're weak on | Self-assessment against AZ-104 skills outline |

## Weekly Time-Budget Suggestion (8–10 hrs/week)

- **3–4 hrs** — video course / Microsoft Learn content
- **3–4 hrs** — hands-on labs / project work (this is non-negotiable — don't let video-watching crowd it out)
- **1–2 hrs** — practice questions / spaced review of earlier material

## Notes on Pacing

- If you can only manage 4–5 hrs/week, roughly double the timeline (~12 months instead of 6).
- Don't wait until "AZ-104 is done" to start projects — running them in parallel (as scheduled above) reinforces the exam material and means you're not starting your portfolio from zero after the exam.
- If you stall on a topic for more than a week, that's a signal to switch from video to hands-on labs for that topic — most people retain Azure concepts far better by doing than by watching.
